The Ultimate
Tabular ML Framework.

Seamlessly ensemble 32 state-of-the-art architectures using stochastic Hill Climbing optimization. Zero manual tuning required.

from omnitabular import OmniTabular
from sklearn.datasets import load_breast_cancer

X, y = load_breast_cancer(return_X_y=True)

# Train 32 models & optimize weights
model = OmniTabular(task="classification", verbose=True)
model.fit(X, y)

print(model.leaderboard())

API parameters

Initialize OmniTabular() dynamically configures the ensemble environment.

Argument Target Mapping
task Can manually set "classification", "regression", or defer to "auto" target scanning.
[model]_params Apply hyperparameter dictionary overwrites (e.g., lgb_params={"n_estimators": 100}, rf_params={"max_depth": 7})
hc_params Configure the stochastic Hill Climbing solver configuration (e.g. {"n_iterations": 100}).
cv_folds Define how many OOF (Out of Fold) segments the initial data pool receives (default = 5).

Core Methods

  • model.fit(X, y) Builds independent out-of-fold instances, scores local metrics, then optimizes terminal weights across standard models.
  • model.predict(X) Forward-passes array mappings using terminal OOF-computed ensemble weights.
  • model.leaderboard() Outputs standard Pandas DataFrame visualizing internal metric evaluations ranking architecture accuracy.
